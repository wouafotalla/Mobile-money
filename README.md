# Mobile Money Transactions Reconcialliation
Transactions reconcilliations
After Mobile Money transactions through an external provider. At the end of each day, the company receives:

Mobile Money(MTN mobile transactions or Orange money transaction) Provider Report — transactions reported by the provider.
Internal Transaction Ledger — transactions recorded by the company's system.

The objective is to have a Python engine that compares the two datasets and produces a reconciliation report.
